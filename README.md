# mephi_db

[Сессионное задание] Итоговый проект. База данных
4 Базы данных:
* транспортные средства
* автомобильные гонки
* бронирование отелей
* структура организации

## Структура проекта

```
mephi_db/
├── docker-compose.yml          # PostgreSQL + Flyway
├── docker/
│   ├── init-databases.sql      # создание 4 БД при старте
│   └── migrate-all.sh          # проведение миграции во все БД
├── db1_vehicle/                # БД 1 — транспорт
│   ├── migrations/V1__init.sql # схема и тестовые данные
│   ├── solutions/task01.sql
│   └── solutions/task02.sql
├── db2_racing/                 # БД 2 — гонки
├── db3_hotel/                  # БД 3 — отели
├── db4_employees/              # БД 4 — сотрудники
└── scripts/
    ├── verify-solutions.sh     # проверка всех решений
    └── expected/               # эталонные ответы для скрипта
```

В `migrations/` — то, что применяет Flyway.</br>В `solutions/` — запросы к задачам, НЕ запускаются автоматически

## Структура баз данных

### 1. База `vehicle` — транспортные средства

- Таблица `Vehicle` — справочник моделей. Хранит производителя (`maker`), название модели (`model`) и тип ТС (`Car`, `Motorcycle`, `Bicycle`). Первичный ключ — `model`.
- Таблица `Car` — легковые автомобили. Содержит VIN, модель (ссылка на `Vehicle`), объём двигателя, мощность в л.с., цену и тип коробки передач (Automatic/Manual). Первичный ключ — `vin`.
- Таблица `Motorcycle` — мотоциклы. Аналогично: VIN, модель, объём, мощность, цена, тип мотоцикла (Sport/Cruiser/Touring).
- Таблица `Bicycle` — велосипеды. Серийный номер, модель, количество скоростей, цена, тип (Mountain/Road/Hybrid).
- Все три специализированные таблицы связаны внешним ключом с `Vehicle`.


### 2. База `racing` — автомобильные гонки

- `Classes` — классы автомобилей. Включает название класса, тип (Racing/Street), страну, число дверей, объём двигателя, вес.
- `Cars` — конкретные автомобили. Название, класс (ссылка на `Classes`), год выпуска.
- `Races` — гонки. Название и дата проведения.
- `Results` — результаты участия машин в гонках. Связывает автомобиль и гонку, указывает финишную позицию. Составной первичный ключ из пары (car, race).

### 3. База `hotel` — бронирование отелей

- `Hotel` — отели. ID, название, местоположение.
- `Room` — номера в отелях. ID, ID отеля, тип номера (Single/Double/Suite), цена, вместимость.
- `Customer` — клиенты. ID, имя, email (уникальный), телефон.
- `Booking` — бронирования. ID, ID номера, ID клиента, даты заезда и выезда.
- Связи: `Room` ссылается на `Hotel`, `Booking` ссылается на `Room` и `Customer`.

### 4. База `employees` — сотрудники организации

- `Departments` — отделы. ID и название.
- `Roles` — роли сотрудников. ID и название роли (Менеджер, Директор, Разработчик и т.д.).
- `Employees` — сотрудники. ID, имя, должность, ID руководителя (`ManagerID`, ссылка на того же сотрудника), ID отдела, ID роли. Реализована иерархия подчинения.
- `Projects` — проекты. ID, название, даты начала и конца, ID отдела-заказчика.
- `Tasks` — задачи. ID, название, кому назначена (ссылка на сотрудника), ID проекта.
- Все внешние ключи настроены с действиями `ON DELETE CASCADE` или `SET NULL`.

## Требования

- Docker и `docker-compose` (или `docker compose`)

## Запуск базы данных

Выполнить из корня проекта:

```bash
docker-compose up -d
```

Будут подняты контейнер PostgreSQL, созданы четыре базы и применены миграции Flyway

Параметры подключения:

| Параметр     | Значение    |
|--------------|-------------|
| Хост         | `localhost` |
| Порт         | `5432`      |
| Пользователь | `mephi`     |
| Пароль       | `mephi`     |

Остановка:

```bash
docker-compose down
```

Полный сброс данных (пересоздать БД с нуля):

```bash
docker-compose down -v
docker-compose up -d
```

## Проверка решений

Автоматическая проверка всех 13 задач (вывод результата + сравнение с эталоном):

```bash
chmod +x scripts/verify-solutions.sh
./scripts/verify-solutions.sh
```

При успехе в конце: **«ВСЕ ОК: все 13 решений выполнены корректно»**.

## Ручной запуск одного решения

Пример для базы `vehicle` и задачи `task01`:

```bash
docker-compose exec -T postgres psql -U mephi -d vehicle -f - < db1_vehicle/solutions/task01.sql
```

Для других задач заменить название БД и номер задачи
